# FullCalendar

Versión instalada: 7.1.3.

Archivos incluidos:

- `fullcalendar.global.js`: paquete estándar con las vistas y la interacción básica.
- `fullcalendar.css`: estilos estructurales requeridos.
- `bootstrap5/`: tema para Bootstrap 5.
- `locales/es/global.js`: traducción al español.

Orden de carga recomendado:

```html
<link rel="stylesheet" href="~/lib/fullcalendar/fullcalendar.css" />
<link rel="stylesheet" href="~/lib/fullcalendar/bootstrap5/bootstrap5.css" />

<script src="~/lib/fullcalendar/fullcalendar.global.js"></script>
<script src="~/lib/fullcalendar/bootstrap5/bootstrap5.global.js"></script>
<script src="~/lib/fullcalendar/locales/es/global.js"></script>
```

Documentación: https://fullcalendar.io/docs/vanilla-js
